# AIぬりえ本 販売ガイド

ChatGPTとCanvaを使ってAIぬりえ本を作り、Amazon KDPへ出品するまでを説明するランディングページです。

## ファイル

- `index.html`：LP本体
- `assets/`：プロフィール画像・特典バナー

## 公開方法

GitHub Pagesで公開します。

1. このフォルダの中身をGitHubリポジトリへアップロード
2. リポジトリの「Settings」→「Pages」を開く
3. 「Deploy from a branch」を選択
4. ブランチを「main」、フォルダを「/root」に設定
5. 「Save」を押す

## 更新するとき

文章は `index.html` を編集します。画像を差し替える場合は、`assets` フォルダ内の同名ファイルを置き換えます。
